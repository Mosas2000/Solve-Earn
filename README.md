# Solve-Earn

Decentralized bug bounty platform on Stacks blockchain.

## What is Solve-Earn?

Solve-Earn enables trustless security vulnerability reporting and rewards. Projects create bounty vaults with predefined severity tiers, researchers submit findings, and smart contracts handle verification and payouts.

## Key Features

- Trustless escrow system
- Automated payout verification
- Researcher reputation tracking
- Multi-signature dispute resolution
- Transparent audit trail
